Key Storage Best Practices

  • Private keys (signing-private.jwk, encryption-private.jwk): Store in 1Password, HashiCorp Vault, AWS Secrets Manager, or similar secure storage.
  • Signing private key: Only needed in your CI/CD pipeline when signing blocklist updates.
  • Encryption private key: Only needed when viewing forensics data in the Forensics Viewer.
  • Public keys: Can be safely distributed in extension configuration files.
  • Backup: Store encrypted backups of private keys. Lost keys cannot be recovered.
